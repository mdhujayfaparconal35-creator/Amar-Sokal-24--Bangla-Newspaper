# নিজের সার্ভারে APK রাখার নিয়ম (দ্রুত ডাউনলোডের জন্য)

1. GitHub → Actions → সর্বশেষ বিল্ড → নিচে Artifacts থেকে `amarsokal24-apk` নামান, জিপ খুলে `amarsokal24-<ভার্সন>.apk` পাবেন।
   (বিল্ডের Summary-তে সাইজ ও আপলোডের লিংকও লেখা থাকে)
2. cPanel → File Manager → `public_html` এর ভেতরে `app` নামে ফোল্ডার খুলুন (একবারই)।
3. ওই ফোল্ডারে `.htaccess` নামে ফাইল বানিয়ে `htaccess_for_app_folder.txt` এর লেখা বসান (একবারই)।
4. APK ফাইলটি `app` ফোল্ডারে আপলোড করুন। প্রতি ভার্সনে নতুন নাম, তাই পুরনো ক্যাশ নিয়ে ঝামেলা নেই।
5. ব্রাউজারে খুলে দেখুন: https://amarsokal24.com/app/amarsokal24-১.১৫.৭.apk (ইংরেজি সংখ্যায়) — ডাউনলোড শুরু হলে ঠিক আছে।
6. T2 → "অ্যাপ আপডেট": APK লিংকে ওই লিংক, Build `25`, Version `1.15.7` দিন।

Cloudflare ব্যবহার করলে `amarsokal24.com` অরেঞ্জ-ক্লাউড (Proxied) রাখুন; .apk ফাইল Cloudflare নিজেই ক্যাশ করে, বাংলাদেশ থেকে দ্রুত দেয়।
